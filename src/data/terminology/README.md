# 点睛术语候选数据

这是用于算法实验的开放词库。完整保留已选来源的词头，按图书主题提供候选词；**词在库中不代表这一处应该高亮**。当前生产阅读器尚未加载这些数据。

## 收录范围

- THUOCL：固定提交 `a30ce79d895d01ab5132a5c74c29703ff7efb4cc` 的全部 11 个词表，共 157,172 行；同表重复词合并，保留最大的有效文档频次。来源：[THUOCL](https://github.com/thunlp/THUOCL)，许可证见 [THUOCL-LICENSE.txt](THUOCL-LICENSE.txt)。包括 IT、动物、财经、汽车、成语、地名、食物、法律、历史名人、医学、诗词。
- Wikidata：查询 `instance of / subclass of* philosophical concept (Q33104279)`，收录查询返回的全部中文、简体、繁体标签。快照含 330 个实体、550 行标签、424 个不同写法，实体 ID 与语言标记保存在 `snapshots/`。这是该查询的结果，不是全部哲学词汇。结构化数据采用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。
- LightRead 自编核心词：各领域少量常见概念与中华思想文化补充词。随项目许可证开放；不冒充官方术语表，也不复制官方释义。

合并后共 **156,965 个不同写法、35 个词包**。同一词可属于多个词包和学科；数量按写法去重，不代表不同概念的数量。简繁转换与同义词归并尚未做，不能把字形相近直接视为同义。

THUOCL 的频次是上游语料的文档频次，语料较早，不能用来代表当前热度或阅读重要性。上游有四行频次异常（`3?`、`125472s`、空值等），词头全部保留，频次记为 `null`，原值与行号记在 `coverage.json`。原始文件 SHA-256 校验在解析之前完成；支持 LF、CRLF、CR 换行。

## 重建与验证

```bash
node scripts/build-terminology.mjs
npm run test:terminology
npm run audit:keywords
```

`sources.json` 固定下载 URL、版本、SHA-256 和许可；THUOCL 缓存在 `~/.cache/lightread/terminology`。Wikidata 使用仓库中的已校验快照，普通重建不会重新查询实时数据。更新快照时重新执行所记录的 SPARQL，检查结果范围，再更新日期、哈希和覆盖报告。

`dictionary.json` 是生成文件，`coverage.json` 是覆盖与异常记录，修改种子词请改 `catalog.json` 后重建。候选模块 `src/services/terminology.ts` 提供带原文偏移的匹配结果和最多 32 词的提示列表，短语候选限制 2–12 个 UTF-16 单元、正文上限 12,000 单元；限制只作用于使用层，不删减源词表。单字概念、较长专业术语仍在数据中，后续需单独评估其展示规则。
