# 阅读器面板 v2：「排版」与「模式」的分工

> 2026-10-17 · 状态：已实现 v2 · 版式回到「排版 › 页面」，带读改为列表 · 范围：可重排书籍阅读器（`ReaderView`）
> 相关：`docs/reading-modes.md`（各模式细节）、`docs/continuous-scroll.md`（跨章连续滚动）、`src/services/readingModes/presets.ts`（快照引擎）

## 1. 问题

改版前两个面板各管一部分，又互相重叠：

| 重叠 | 「排版」里 | 「模式」里 |
|---|---|---|
| 正文主题 | 主题圆点（含米黄、护眼绿、夜间） | 夜间卡片、护眼卡片（含「底色」米黄 / 护眼绿） |
| 分栏 | 分栏：单栏 / 自动双栏 | 双栏卡片（同一个设置） |
| 字号等 | 字号、行距、边距、字体 | 大字卡片（大 / 特大） |
| 页眉页脚 | 进度显示 | 沉浸 · 隐藏页码 |
| 调暗 | — | 护眼里的「调暗」（只在暖色主题下生效） |

同一个值有两个入口，读者不知道该去哪改，也不知道两边谁说了算。字距、两端对齐会被「大字」改掉，却没有任何地方能手动调。

## 2. 原则

1. **排版 = 书页长什么样、怎么翻。** 文字、配色和版式只在这里调，每个值只有这一个家。
2. **模式 = 此刻的场景与带读。** 点睛阅读、场景，以及自动翻页 / 自动滚动、打字机、歌词、听书；各带读行说明当前生效版式下怎么读，通过「当前翻页 / 滚动，改」跳到排版的页面分区。
3. **场景是快捷方式，不是第二份设置。** 「模式」顶部的场景卡片一键套用一组排版值（走现有的快照引擎：开启记下原值，关闭写回），自己不保存任何排版值的副本，也不在详情里放排版控件，只列出「会调整什么」并提供「在排版里微调」的跳转。
4. **场景详情里只放场景自己的行为**：什么时候自动开启（夜读定时）、开着时做什么（护眼的休息提醒）、选哪一套（大字的大 / 特大）。
5. **互相跳转代替重复**：模式 → 排版（「在排版里微调」，定位到对应分区）；排版 → 模式（场景提示条的「管理」）。

## 3. 信息架构

### 3.1 「排版」面板（工具栏「A」，按钮 title 仍是「排版设置」）

| 分区 | 设置 | 存储键 | 备注 |
|---|---|---|---|
| （顶部提示） | 已开场景提示 + 管理 | — | 大字 / 墨水屏 / 沉浸开着时显示，点「管理」打开模式面板 |
| 文字 | 字号 | `reader.fontSize` | A− / 滑条 / A+ / 数字框 |
| | 行距 | `reader.lineHeight` | |
| | 边距 | `reader.gap` | |
| | 字体 | `reader.fontFamily` | |
| | 更多 › 字距 | `reader.letterSpacing` | **新露出**（原先只有大字会改它） |
| | 更多 › 对齐 | `reader.justify` | **新露出**：两端对齐 / 左对齐 |
| | 更多 › 导入字体 | — | 仅桌面版 |
| 配色 | 主题 | `reader.theme` | 白 / 米黄 / 护眼绿 / 夜间 / 跟随外观（5 个圆点，顺序不变） |
| | 调暗 | `readingMode.eyeCare.dim` | **从护眼移来**，改为对所有主题生效 |
| | （墨水屏提示） | — | 墨水屏开着时说明配色按黑白显示 |
| 页面（`data-section="page"`） | 翻页方式：翻页 / 按章滚动 / 连续滚动，三张示意卡片 | `reader.flow` + `reader.continuousScroll` | 翻页不改跨章偏好；两种滚动分别设 `continuousScroll=false/true`；固定版式书隐藏 |
| | 分栏：自动 / 单栏 / 双栏 | `reader.maxColumnCount` | 始终显示，生效滚动时禁用并说明单栏；大字强制单栏时给出说明；固定版式书隐藏 |
| | 手机竖握时改为连续滚动 | `reader.portraitScroll` | 仅 `MQ.touch` 设备显示开关，横过来恢复保存设置；固定版式书隐藏 |
| | 进度 | `reader.progressDisplay` | 页码+百分比 / 页码 / 百分比 |

卡片高亮保存的选择。竖屏锁定或歌词临时滚动时，说明给出当前约束与恢复方式，不回写设置。桌面竖向窗口仍沿用现有竖屏布局逻辑，但不显示触屏开关，提示横向窗口恢复。

文字分区的「更多」用原生 `<details>` 折叠，展开状态按设备记在 `localStorage`（读不到就默认收起）。

### 3.2 「模式」面板（工具栏「阅读模式」，底栏「模式」）

| 分组 | 内容 |
|---|---|
| 运行条（置顶） | 自动阅读、打字机、歌词运行或暂停时显示名称、暂停/继续、退出；有 `progress` 时保留章名、剩余时间和进度条。歌词手动/跟听书不提供无效的暂停按钮 |
| 点睛阅读 | 插槽 `DianjingToggle`，原有总开关、基础/智能选项不变 |
| 场景 | 夜读 · 护眼 · 墨水屏 · 大字 · 沉浸，详情与快照恢复不变 |
| 带读 | 四行列表，标题旁「一次运行一个」；每行独立主按钮，设置按钮互斥展开，`modes.panelTab` 记住上次展开行 |

| 带读 | 当前版式说明 | 外露设置 | 更多 |
|---|---|---|---|
| 自动翻页 / 自动滚动 | 翻页时每隔几秒翻页，滚动时匀速下移，墨水屏时整屏推进 | 速度 | — |
| 打字机 | 翻页时打满一页翻页；滚动时当前行保持在视线处 | 出字、速度 | 后文、标点停顿、墨迹未干、打字声（音色、音量、试听） |
| 歌词 | 一行一行亮起；当前翻页时说明临时滚动、结束恢复 | 换行及对应提示、速度（仅自动） | 聚焦、其余行、位置、字号、标点停顿 |
| 听书 | 朗读这本书；正在听书且歌词未开时提供「显示歌词」 | 打开现有听书面板 | — |

前三行说明后可跳转到排版的 `page` 分区；固定版式书没有该入口，打字机/歌词开始按钮禁用并说明原因。开始另一带读时沿用互斥逻辑，并提示停止了哪个模式；歌词可以跟随听书。手机开始后收起抽屉，桌面保留列表供控制；键盘提示放在主按钮的 title。

歌词的换行选项显示当前实际驱动：听书临时接管时显示「跟听书」并隐藏速度；再点「自动」或「手动」即可切回，即便该选项与之前保存的值相同。此联动不新增存储字段。

三个速度控件统一为 `LevelSlider` 的慢/中/快刻度和右侧数值输入，失焦/回车生效，越界收敛并回显。打字机与歌词共享原速度与预设刻度；自动阅读沿用 1–100 档、3–300 秒范围，输入单位按版式为秒/页或秒/屏。没有加减按钮或预设 chip。

打字机/歌词的常用预设以分段线性映射分布在滑轨的 15% / 50% / 85%，让窄屏刻度有足够间距；滑轨两端仍覆盖完整速度上下限，数值输入与存储单位不变。

### 3.2.1 生效版式只有一个出口

`effectiveReaderLayout()`（`services/portraitLayout.ts`）= 用户保存的翻页 / 分栏 + 临时约束：竖屏锁定（滚动 + 单栏）、歌词运行（`forceScrolled`：滚动 + 单栏）、大字等场景（`forceSingleColumn`：单栏）。约束**不回写设置**，解除后自然回到用户的选择。

分栏默认「自动」：按阅读区域宽度与方向选择一栏或两栏，随窗口变化重排；「单栏」「双栏」固定栏数。滚动、竖屏单栏连续和大字等临时约束优先，解除后恢复原选择。设置版本 15 将旧「自动双栏」（`maxColumnCount: 2`）迁为 `auto`，旧单栏保持不变。

带读一律不写用户设置：歌词的滚动是 `forceScrolled`，字号 ×倍数、行距 ≥2.0 是 `modes.typographyOverride`（ReaderView 叠加到 `getReaderCSS` 的生效值，变化经 `renderKey` 重排）。此前歌词用预设把 `reader.flow`、`fontSize`、`lineHeight` 写进设置，会同步到其他设备、也让排版面板显示被放大的字号；旧版本残留的歌词预设记录启动时照常写回。场景（夜读、护眼、大字、墨水屏）仍是快照预设，因为它们本来就是「一键改一组排版值」。

原先底部的「实验」组（单独的按词着色开关）已并入点睛阅读，成为基础版；两个版本同一时间只生效一个，不再需要「互斥」提示。

### 3.3 场景卡片

| 场景 | 会调整（排版里的值或渲染方式） | 场景自己的选项 | 关闭时 |
|---|---|---|---|
| 夜读 | 主题 → 夜间 | 定时开启（从 / 到） | 主题写回开启前的值 |
| 护眼 | 主题 → 米黄或护眼绿（记住你最后在排版里选的暖色） | 休息提醒（20 / 30 / 45 分钟） | 主题写回 |
| 墨水屏 | 黑白高对比、文字加粗、无翻页动画；打字机最少逐句 | — | 打字机粒度写回 |
| 大字 | 字号 24 / 30、行距 2.0、字距、边距、黑体、不两端对齐；强制单栏；工具栏按钮放大 | 大 / 特大 | 排版值写回；在排版里调过的字号等记为大字自己的值，下次沿用 |
| 沉浸 | 隐藏页眉章名与本章剩余；工具栏轻点才出现；手机隐藏状态栏并常亮 | 连页码也隐藏 | 恢复 |

夜读、护眼、大字的详情里有「在排版里微调」，打开排版面板并滚到对应分区（配色 / 文字）。

不做「专注滚动」场景：它等于「排版 › 页面 › 连续滚动」，一步即可，包成场景只会多一个入口。

## 4. 迁移与兼容

- **面板重排不改变预设快照格式**；同批分栏与歌词默认值调整分别由设置 v15 / v16 迁移（见文末）。预设快照（`readingMode.presets`）的格式、键名、叠加规则不变，已有记录照常恢复（`test:sync-settings` 覆盖）。
- **双栏卡片删除**：值一直是 `reader.maxColumnCount`，只在排版里调。
- **护眼「底色」选择删除**：在排版里点米黄 / 护眼绿即记为 `readingMode.eyeCare.theme`，下次开护眼用它。
- **调暗改为通用**：`readingMode.eyeCare.dim` 不再只在暖色主题下生效。为了不让老用户突然变暗，首次加载时若当前不是暖色主题而 `dim > 0`（此前看不到效果），把它清零（`localStorage` 标记 `lightread-dim-general`，只做一次）。
- **新露出字距、对齐**：键早已存在并参与同步，只是补上控件。
- 定时夜读、休息提醒、沉浸·隐藏页码仍在模式的场景详情里，键不变。

## 5. 理由

- 读者找设置时按「我想让字/颜色/版面变成什么样」去排版，按「我想被带着读」去模式；两个心智模型不交叉。
- 场景卡片保留「一键 + 可撤销」的价值（关闭即恢复原样，叠开也能正确回退），但不再和排版争夺同一个值的所有权。
- 调暗是夜里最常用的控件，不该只在护眼下可用。
- e2e 选择器：`button[title="排版设置"]`、`.theme-btn`（5 个，第 3 个护眼绿）、排版里的 `[data-section="page"]`、`getByRole('group', { name: '翻页方式' })` 的「翻页 / 按章滚动 / 连续滚动」、`getByRole('group', { name: '分栏' })` 的「自动 / 单栏 / 双栏」；`[title="阅读模式"]`、`.rm-panel`、`.rm-close` 保持不变。
- 带读行使用 `.rm-guide[data-guide="auto|typewriter|lyric|tts"]`，设置按钮 `.rm-gear`（`aria-expanded`），主按钮 `.rm-guide-action`；自动阅读设置容器保留 `.auto-panel`，速度仍可通过 `.auto-panel input[type=range]` 操作。删除 `.tp-jump`、模式的 `data-section="layout"` 和旧页签选择器。


### 2026-10-17 歌词精确控制

聚焦保留 1 / 3 行快捷项，并支持输入 1–99 行。偶数行将多出的一行放在当前行之后，章节边缘按实际可用行裁切。
位置显示采用高度坐标：底部 0、顶部 1，偏上预设为 0.618、居中为 0.5；滑杆按 0.1 调节，输入支持三位小数。0 / 1 端点保持当前行完整可见。
内部 `lyric.anchor` 仍沿用从顶部计量的坐标（高度的 1 减值），避免改变设置同步的意义。设置 v16 将旧偏上 0.4 迁为 0.382，居中值保持不变。
