# K30 真机逐项验收约定

用户于 2026-10-18 要求：在 K30 上自顶向下检查每个栏目、窗口、功能和按钮，记录完整点击过程与结果；阅读长文本使用设备上的《理想国》。

## 顺序与记录

1. 确认设备型号为 Redmi K30 Pro（lmi），记录 Android、WebView、App 版本及 APK 哈希，不能以另一台在线手机代替。
2. 覆盖安装前保存当时藏书、阅读位置和设置，备份元数据；保持应用身份及固定签名，不卸载、不清空数据。
3. 按藏书 → 阅读器 → 论文 → 书源 → 阅读记录 → 设置 → 附属页面检查。每页从顶部到下方，每个二级窗口继续按同样顺序检查。
4. 清单逐项记录入口、按钮／控件、操作、预期、实际、状态和证据。状态分为通过、失败、受阻、待测；打开窗口不代表窗口内功能全部通过，浏览器通过不算真机通过。
5. 覆盖点击、滑动、输入、边界、开关、选中／禁用状态、关闭按钮、Android 返回、弹层返回原页、设置持久化和离开后的恢复。检查截断、换行、遮挡、横向溢出和深浅色。
6. 阅读用《理想国》检查长章节、密度真实变化、连续翻页、打字机隐藏／淡显和听书；测试前记录位置，完成后恢复。删除、标签、移动、转换等数据修改使用单独测试条目。
7. 账号、支付／付费调用、对外发送、云端覆盖、删除真实数据等操作不得为凑点击覆盖率执行；在清单中写明实际验证层级与未执行原因，需要隔离测试数据或专用账号时明确列出。
8. 发现问题后记录复现、修复、构建哈希及真机复验；最终交付报告必须列出尚未通过的项目，不能声称“全部通过”而省略限制。
9. 私有书页、账号、密钥、手机完整数据库和原始截图仅放在本机受限目录。仓库报告只记录必要测试结果。结束后停止测试音频，恢复修改过的偏好，核对原有书架和阅读位置。
