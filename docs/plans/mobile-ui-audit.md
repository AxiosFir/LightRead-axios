# 手机交互与文案审查（2026-10-17）

本轮从 AI 服务选择扩展到全局选择 / 确认控件，并补充歌词精确控制。未涉及书籍正文或用户自己输入的文字。

## 应用内弹层

- `AppModal` 统一手机底部抽屉、桌面居中、固定标题 / 关闭 / 底部操作、滚动正文、安全区、背景禁用、焦点约束与返回恢复；支持 Escape、浏览器 CloseWatcher；路由守卫在 Android 返回时优先关闭最上层弹窗并留在原页。
- `AppSelect` 替换全局原生下拉：AI 通道、代理、藏书排序、字体、音色、点睛体裁、互传、上传目标 / 书单、手册目录、论文翻译语言和 Agent 多选。支持分组、数字值、多选、键盘导航；超过 12 项提供搜索。
- 保留选择控件的单根触发按钮，使父页面 scoped 样式继续生效。藏书页维持“标题 + 导入 / 搜索 + 排序 + 管理”的原排列；320 / 360 / 392 px 回归检查排列及排序文案完整显示，避免替换控件改变页面布局。
- Android 弹层直接监听 Tauri 返回事件；即使恢复应用后没有 WebView 历史，也先关闭弹层。卸载弹层时解除监听，恢复应用原本的返回行为。
- `askConfirm` 替换删除书籍 / 书单 / 标签 / 书源 / 互传记录、恢复备份、切换书库的浏览器确认。取消、关闭及离开页面均取消待执行操作；保留原有警告信息。
- 设置页的密钥同步与断开网盘确认也采用统一弹层。夜间时段改为 HH:MM 输入，避免系统时间选择弹窗。
- 文件 / 目录选择、系统权限及安装器是平台功能入口，保留系统界面。

AI 通道按内置试用、硅基流动、DeepSeek、智谱、千问、Kimi、豆包、Ollama、自定义排列。DeepSeek 官方接口及默认模型依据 https://api-docs.deepseek.com/ 核对。重复选择当前通道不重置自定义模型 / 地址；切换新预设才填入默认配置。试用及 Ollama 不显示无需填写的 API Key 字段。

## 文案

以 320 / 360 / 392 CSS px、中英文检查藏书、论文、书源、设置、统计、互传、手册导航，共 42 个主页面状态；另检查 AI 选择弹层及阅读面板。脚本 `scripts/audit-mobile-copy.mjs` 用实际文字行框统计超过两行的文字，产物位于 `/tmp/lightread-global-ui/copy-audit.json`。

审阅及处理：

- 藏书空态、导入提示：审阅后按用户最新要求保留原文与页面布局，仅替换弹窗交互。
- 推荐书单：缩短重复的背景介绍，保留主题、获奖年份与免费版本提示；同步修改生成脚本中的奖项说明。
- 设置与互传：压缩 AI 简介、通道副标题、功能介绍、排版重置、代理说明和互传准备步骤。
- 关于页：完整格式列表放在“支持的文件格式”展开项中，按需阅读，不截断。
- 删除范围、不可恢复提示、密钥共享说明、应用密码获取路径：审阅后保留必要内容；长书名、路径、错误详情允许换行，不通过隐藏或省略制造错误理解。
- 使用手册正文、书籍内容、用户数据、远端搜索结果不是界面提示，不按两行截断。

## 歌词

保留一行 / 三行预设，支持输入 1–99 行；高度显示为底部 0、顶部 1，默认 0.618，居中 0.5。滑杆 / 方向键以 0.1 调节，手动输入精确到三位小数；两端保证当前行完整可见。内部继续保存从顶部计量的 anchor，设置 v16 迁移旧偏上预设，保留居中与新版自定义值。

验证入口：`scripts/e2e-ui-controls.mjs`、`scripts/e2e-mobile.mjs`、`scripts/e2e-smoke.mjs`、`scripts/test-reading-modes.mjs`、`scripts/test-sync-settings.mjs`。真机验收使用 K30 的原包名与固定签名覆盖安装，不卸载或清空数据。
