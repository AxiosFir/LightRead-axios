# App 2.0 功能与界面验证（2026-10-17）

工作分支：`Dev`；工作目录：`LightRead-v2`。以 `d32657a` 为基线完成修复。App 按 Android 平台构建为 2.0.0，桌面仍按 Linux 平台构建为 1.20.0。本次没有发布 Release，也没有覆盖已连接手机上的 1.x 安装。

## 修复的问题

1. **场景开关无法正常轻点**：App 将说明按钮移到单独一行后，沿用了旧的绝对定位扩展热区，热区覆盖整个场景卡片。移除这层重复热区，保留说明按钮自身的触控尺寸；夜读、护眼、墨水屏、大字、沉浸均逐项点击开启／关闭，并检查排版恢复。
2. **点睛弹层漏接 App 交互管理**：首次智能版说明、概念卡、脉络、速读没有加入统一面板状态。现接入背景禁止交互、焦点循环、关闭请求处理；平板宽度也应用焦点约束。浏览器 Tab / Escape 已验证，Android 返回仍需目标真机复验。
3. **听书进度跟错页面**：边听第二章边浏览第一章，播放器会显示第一章的进度与剩余时间。现在按朗读句的位置更新章名、全书百分比、章节进度、剩余时间与听书书签，正文仍可独立浏览。字数位置按文档缓存索引，避免每句从章首重复扫描。
4. **离开朗读页后“听完本章”失效**：同一分节含多个章节时，以浏览页变动判断结束不可靠。现按朗读位置检查章节边界，已用双章 TXT 验证浏览其他章节期间仍可暂停。停止播放同时清除待执行的跳句任务，避免旧任务启动新的播放。
5. **窄屏听书标题重叠**：320px 宽度下，定时徽标会覆盖居中的听书标题。标题与收起／停止控件改用网格定位，定时状态另占一行。
6. **生成书封挡住操作按钮**：书封文字的层级高于书卡操作区，导致上传等按钮虽可见却点不到。提升 App 书卡操作区层级，并以真实点击完成上传回归。

同时修正了测试里的旧桌面版本断言、旧手机菜单选择器及固定端口冲突；私人书库测试改为可对生产构建执行。Vite 忽略原生生成目录，避免 Rust 编译产物耗尽 Linux 文件监听额度。
