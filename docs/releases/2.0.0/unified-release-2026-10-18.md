# 2.0.0 统一发布

2026-10-18 用户确认桌面版可以仅升级版本号，以便与 App 统一管理。

- 统一标签 `v2.0.0`、Release 标题 `v2.0.0`，全平台通过门禁后设为 latest。
- Android 1.20.1 只接受 `vX.Y.Z`，因此忽略原 `app-v2.0.0`。统一发布恢复旧安卓与旧桌面的更新入口；App 更新器也增加统一标签兼容。
- 桌面沿用已发布 1.20.0 安装包的源码 `1f65e15f447767d01ede13638dcc8d6df4724a0f`，原始元数据为 1.19.4。构建时只改五个文件中的六处版本值为 2.0.0，逐行检查补丁；应用源码、依赖和身份保持不变。
- Windows x64、macOS arm64/x64、Linux x64 分别原生构建并校验安装包内版本，提供构建报告与版本补丁。Android 保持原包名、固定签名、arm64 debug 分发形式。
- 原 `app-v2.0.0` 不移动标签或替换资产；它的旧 APK 仅支持 App 标签。后续首个大于 2.0.0 的版本须额外提供同 APK 的 `app-vX.Y.Z` 兼容入口（latest=false），使这批用户迁移到统一更新器。

原 210 项 K30 记录（201 通过、9 受阻）保留其对应 APK 的原始结论。本次只改更新器与版本元数据，追加构建、更新链路和覆盖安装的数据保留检查，不把旧 APK 的测试标成新包的重新实测。
