# v2.1.0 PDF 双形态阅读

文字版 PDF 可以在本机转为电子书形态，复用字号、主题、分页／滚动、听书及阅读模式。原始 PDF 文件保持不变，可按当前页和段落位置切回原版；扫描版与论文默认原版。设置可选择始终原版，每本书在本机记住手动切换结果。

源码：桌面／默认 Web 的功能提交 `ef05a36c3da912635c824789ab07c280752a03d0`；App 在此基础上接入 `src/mobile/` 的独立页面，保留 App 2.0 界面。桌面安装包从固定功能提交做版本补丁构建，各原生平台附构建报告；Android 从统一标签构建，沿用固定签名和 `com.yzfly.lightread.debug`、arm64、API 24/36。

已完成的发布前验证：

- 18 项 PDF 重排测试，包含 MuPDF 生成的真实 PDF、段落／图表／目录／判定／页码锚点。
- 设置同步、合并与更新器回归，App 平台边界和更新标签校验。
- 桌面生产构建及完整阅读器／更新流程浏览器冒烟，无页面错误。
- 313 页公开授权《深入理解 AI Agent》在桌面浏览器完成电子书 → 原版 → 电子书往返，定位到第 15 页后继续阅读，无页面错误；原书只保存在本机测试缓存，不随源码发布。
- App 生产构建；桌面版本补丁只修改五个文件中的六处版本值，版本一致性检查通过。
- 新增的 `e2e:pdf-reflow` 在桌面自制样本及 App 313 页公开样本上通过：自动电子书、进度跳转、切换往返、刷新后记住形态、扫描版保持原版且禁用重排；均无页面错误。

限制：扫描版 OCR、竖排、两种形态的划线互显尚未提供；每本书的形态选择和精确 CFI 只存在本机，跨设备进度仍以 PDF 页码保存。图表／公式／表格使用裁切图片，复杂图中的少量文字及标题可能误判。首次打开要等待文字转换完成，图按章节加载时渲染。性能尚不能承诺所有手机达到原方案的首屏目标；本次不提供 iOS 安装包。

本文件只记录已经执行的检查，后续构建、真机及发布下载验证完成后追加结果。
